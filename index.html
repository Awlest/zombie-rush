Comment jouer

  • 👉 Glisse ton doigt en bas pour déplacer ton escouade qui tire toute seule.
  • 🚪 Traverse les portails (×2, +10…) pour multiplier ton équipe. Évite les rouges !
  • 📦 Roule sur les caisses d'armes pour changer d'arme (fusil, sniper, roquette…).
  • 🛡️ Ramasse les bonus : Bouclier, Tir rapide, Bombe.
  • 💀 Tue les zombies avant qu'ils touchent ton escouade. Un boss t'attend tous les 5 niveaux.
  • ⏱ Termine vite pour gagner 3 étoiles !
